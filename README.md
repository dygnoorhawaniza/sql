# 🗃️ SQL Practice & Data Analysis

A collection of SQL exercises and practice queries created while learning SQL for data analysis.

### 📚 Topics Covered

* `SELECT` & filtering
* `GROUP BY` & `ORDER BY`
* `WHERE` vs `HAVING`
* `JOIN`
* `UNION`
* String functions
* Subqueries
* CTEs
* Window functions
* Temporary tables
* Stored procedures
* Triggers & events
* Data cleaning
* Data analysis

### 📊 Practice Dataset

The repository also includes a layoffs dataset used to practise **data cleaning and analysis** with SQL.

### 🛠️ Tools

`SQL` · `MySQL`

### 🌱 Learning Goal

Building a stronger foundation in SQL and developing practical skills for data analysis.
